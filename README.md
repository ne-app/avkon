# Ne.app Avkon

A free C++ SDK written in Modern C++ for desktop applications.

## Rationale:

Written in C++, the SDK lets you write beautiful C++-based applications using web based technologies.

## Contents:

- Store System.
- RAD C++ API.
- PDF System.
- C++ RAD System.

## Support:

You can support the Avkon SDK via GitHub sponsors, custom development is also available.
